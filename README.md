## How I approach quality

- Prevent defects early: trace every test to a requirement and close gaps before code ships.
- Automate the repeatable, explore the risky.
- Treat a failed transaction as a story: follow it through terminal, service and host logs to the root cause.
- A release is ready when the evidence says so, not when the calendar does.
